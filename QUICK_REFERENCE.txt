┌──────────────────────────────────────────────────────────────────────────────┐
│ 📋 COMMAND LINE OPTIONS                                                      │
└──────────────────────────────────────────────────────────────────────────────┘

  --bolt                          Enable BOLT optimization
  --pgo <benchmark>              Enable PGO with benchmark
                                 (kernel-defconfig-slim recommended)
  --lto <thin|full>              Enable LTO (thin recommended)
  --mlgo <model_path>            Enable MLGO (NEW!)
  --assertions                    Enable assertions (recommended with BOLT+PGO)
  --install-folder <path>        Installation directory
  --vendor-string <name>         Custom vendor string
  --targets <arch> [arch...]     Target architectures
  --linux-folder <path>          Linux source for PGO/BOLT
  --build-stage1-only            Quick single-stage build
  --quiet-cmake                   Reduce cmake output
  --show-build-commands          Show build commands

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 COMMON ISSUES & SOLUTIONS                                                 │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: BOLT crashes with PGO
  ┌────────────────────────────────────────────────────────────────────┐
  │ Solution: Add --assertions flag                                    │
  │ ./build-llvm.py --bolt --pgo kernel-defconfig-slim --assertions    │
  └────────────────────────────────────────────────────────────────────┘

  Problem: Out of memory during LTO
  ┌────────────────────────────────────────────────────────────────────┐
  │ Solution: Use ThinLTO and limit parallel jobs                      │
  │ ./build-llvm.py --lto thin \                                       │
  │     --defines LLVM_PARALLEL_LINK_JOBS=2                            │
  └────────────────────────────────────────────────────────────────────┘

  Problem: MLGO model not found
  ┌────────────────────────────────────────────────────────────────────┐
  │ Solution: Verify model path exists and is a directory              │
  │ ls -la /path/to/mlgo/model                                         │
  └────────────────────────────────────────────────────────────────────┘

  Problem: Build takes too long
  ┌────────────────────────────────────────────────────────────────────┐
  │ Solution: Use lighter configuration or increase parallel jobs      │
  │ ./build-llvm.py --lto thin \                                       │
  │     --defines LLVM_PARALLEL_COMPILE_JOBS=$(nproc)                  │
  └────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────┐
│ 📝 TIPS & TRICKS                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

  ► Use ccache for faster stage-1 rebuilds (enabled by default)
  ► kernel-defconfig-slim is fastest PGO option with good results
  ► ThinLTO has 99% of Full LTO performance with much less RAM
  ► Combine --pgo + --lto + --bolt for best results without MLGO
  ► Add --assertions when using BOLT + PGO together
  ► Use --linux-folder to avoid re-downloading kernel source
  ► Set LLVM_PARALLEL_*_JOBS based on available RAM
  ► Test with --build-stage1-only before long optimized builds

┌──────────────────────────────────────────────────────────────────────────────┐
│ ⚠️  IMPORTANT NOTES                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

  • MLGO requires TensorFlow C API installed on system
  • All optimizations are optional and can be combined
  • Build times increase significantly with more optimizations
  • Performance gains are cumulative when combining optimizations
  • Always ensure adequate RAM for chosen configuration
  • Use SSD for faster builds (HDD will be much slower)
