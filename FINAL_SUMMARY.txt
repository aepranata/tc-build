TROUBLESHOOTING:

Issue: MLGO model not detected
Solution: 
  - Check model location: ls -la src/mlgo-model/
  - Read: cat MLGO_SETUP.md

Issue: Build fails with MLGO
Solution:
  - Ensure TensorFlow C API installed
  - Verify model format (SavedModel)
  - Check build.log for details

Issue: Out of memory
Solution:
  - Use ThinLTO instead of Full LTO
  - Reduce parallel jobs: LLVM_PARALLEL_LINK_JOBS=2
  - Use smaller build preset

Issue: Build too slow
Solution:
  - Use SSD instead of HDD
  - Increase parallel jobs if RAM permits
  - Use build-examples.sh preset #2 (LTO only)

For more: See BUILD_OPTIMIZATIONS.md - Troubleshooting section
