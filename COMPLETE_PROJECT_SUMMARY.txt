TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════

Common Issues:

1. MLGO model not detected
   → Check: ls -la src/mlgo-model/
   → Fix: Place model in correct location
   → Guide: cat MLGO_SETUP.md

2. Build fails with MLGO
   → Check: TensorFlow C API installed
   → Check: Model format (SavedModel)
   → Log: cat build.log

3. Out of memory
   → Use: ThinLTO instead of Full LTO
   → Reduce: LLVM_PARALLEL_LINK_JOBS=2
   → Choose: Smaller build preset

4. Build too slow
   → Use: SSD instead of HDD
   → Increase: Parallel jobs (if RAM permits)
   → Choose: Lighter build preset

For detailed troubleshooting:
  → Read: BUILD_OPTIMIZATIONS.md - Troubleshooting
  → Read: QUICK_REFERENCE.txt - Common Issues
